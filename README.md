# chefshand_godot

DESCRIPTION: Chef’s Hand is a drag-and-combine cooking puzzle game where you put ingredient cards together to find new recipes.

HOW TO PLAY:
1. Open full screen on Itch.io
2. Click Play on the home screen
3. Click Next once you have read the instructions
4. Click an ingredient on the left to spawn its corresponding cards
5. Drag ingredients together to test combinations
6. If a combination works, a new recipe is created and added to your list on the left
7. If it doesn’t work, the cards will flash red and you can try again
8. Drag unwanted cards into the trash can to remove them

Discover all 21 recipes to complete the game and see your final time!

CHEAT SHEET (use this only if you are stuck):

  Egg + Flour → Brownie
